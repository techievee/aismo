# aismo feature screenshots

Screenshots from the app, each showing one of its features. The inbox in these shots is
populated with demo messages: an Indigo flight notice (Travel), a login OTP, an
electricity bill (Bills), a bank debit (Finance), and a Hindi personal message.

| File | Feature shown |
| --- | --- |
| `01-inbox.png` | The inbox: conversations sorted into categories, unread badges, the category bar along the bottom. |
| `02-thread-translation.png` | A conversation: a Hindi message with on-device translations to English and French shown under the original. |
| `03-search-meaning.png` | Search by meaning: "power bill" finds the electricity notice under "Similar in meaning", with no shared words. |
| `04-search-keywords.png` | Keyword search: "bill" matches and highlights the word in the message. |
| `05-finance.png` | Finance: the month's spending summary, budgets, and the transactions parsed from bank alerts. |
| `06-reminders.png` | Reminders: a bill detected from a message, with its due date, amount, and "Add to calendar". |
| `07-blocked-senders.png` | Blocked senders. |
| `08-translation.png` | Translation settings: auto-translate and the phone's language. |
| `09-security-settings.png` | The Security group: unlock categories, the PIN, the unlock method, and the unlock window. |
| `10-rules.png` | Rules: a rule that files messages from a given sender under a chosen category. |
| `11-custom-categories.png` | Custom categories: a user-created category with its own icon. |
| `12-inbox-categories-locked.png` | The inbox-categories page behind its lock: it asks for the fingerprint or the PIN. |
| `13-inbox-categories.png` | Inbox categories: per-category show/hide, alerts, and secured chips, plus reordering. |
| `14-backup-and-restore.png` | Backup and restore: the encrypted backup, its location, passphrase, schedule, and restore. |
| `15-composer.png` | The new-message composer: recipient, text, attachment, rewrite, and send. |
| `16-about.png` | About: the app, its version, and the help pages. |
| `17-privacy.png` | Privacy and permissions: what stays on the phone, and why each permission is asked for. |
| `18-locked-category.png` | A secured category after a restart: a padlock in its place in the bottom bar, no badge, and its messages absent from All until unlocked. |
